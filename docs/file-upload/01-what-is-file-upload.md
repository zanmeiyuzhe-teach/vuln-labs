# 文件上传漏洞

## 概述

文件上传漏洞发生在应用程序允许用户上传文件但没有正确验证文件类型、内容或扩展名时。攻击者可以上传恶意文件（如 Webshell）来执行任意代码。

## 攻击原理

```
用户上传文件 → 服务器验证不足 → 恶意文件被保存
→ 访问恶意文件 → 执行任意代码
```

## 常见验证方式

### 1. 前端验证

JavaScript 检查文件扩展名，容易绕过（禁用 JS 或直接发请求）。

### 2. MIME 类型检查

检查 `Content-Type` 头，可伪造。

### 3. 扩展名检查

检查文件扩展名，可通过大小写、双写、特殊扩展名绕过。

### 4. 文件内容检查

检查文件头（magic bytes），需要在文件头添加正确的标识。

### 5. 二次渲染

服务器重新处理图片，可能在处理过程中保留恶意代码。

## 常见 Webshell

### 简单 Webshell

```php
<?php system($_GET['cmd']); ?>
```

### 一句话木马

```php
<?php eval($_POST['code']); ?>
```

### 图片马

将 PHP 代码添加到图片文件中：

```bash
copy /b image.jpg + shell.php image.jpg
```

## 防御方法

1. 使用白名单验证扩展名
2. 验证文件内容（magic bytes）
3. 重命名上传文件
4. 将上传目录移到 Web 根目录外
5. 禁止上传目录执行 PHP

## 靶场

- Easy: 前端验证绕过
- Simple: MIME 类型绕过
- Hard: 扩展名 + 内容检查绕过
- Hell: 全面防护绕过
